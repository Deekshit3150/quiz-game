# 🧠 Python Quiz Game with IQ Evaluation

This is a fun and interactive **Quiz Game** built with Python that includes:
- Multiple difficulty levels (easy, medium, hard)
- A countdown timer ⏱️ for each question
- Lifelines like **50-50** and **Skip** 🎯
- A scoring system with IQ level evaluation
- A simple leaderboard to track high scores 🏆

---

## 📌 Features

- ✅ **Multiple Choice Questions**
- 🔥 **Difficulty Levels:** Easy, Medium, Hard
- ⏳ **Time Limit:** 10 seconds per question
- 🛟 **Lifelines:**
  - **50-50**: Removes two wrong options
  - **Skip**: Skip a question without penalty
- 🧠 **IQ Level Calculation**
- 📊 **Leaderboard** with top scores

---

## 🚀 How to Run

1. Clone the repository or download the script.
2. Make sure you have Python 3 installed.
3. Run the game using:

```bash
python quiz_game.py
